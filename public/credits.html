BIT CHEER / SOURCE NOTES

Bit Cheer is an independent beatmatching trainer. These artists and early desktop designs helped make it possible. Credit and license details stay with the bundled assets.

The practice recordings

These real recordings are licensed under Creative Commons Attribution 3.0. Each bundled file is a 64-beat excerpt, re-encoded to 160 kbps MP3 with short edge fades. Tempos are estimates; listen and calibrate the cue by ear.

  • Selection — abece · House · 130 BPM. Original & license · Practice excerpt
  • My First House Tweek — TEAMFOCUS · House · 123 BPM. Original & license · Practice excerpt
  • 21seiki Techno Shonen — emanon · Techno · 148.19 BPM estimated. Original & license · Practice excerpt
  • Robowalk — sausageblowfly · Techno · 130 BPM. Original & license · Practice excerpt

The beginner loops use a local learned Markov rhythm model trained on 20 original authored patterns, with Rust synthesizing the voices. No neural or cloud music service is used. These generated loops are separate from the recorded-track library.

Practice inspiration

Beatmatch PRO inspired genre-based track discovery. The catalog retains 574 public artist links from that practice library. Original audio stays with the artists on Bandcamp: open a source, obtain the track, then import your file into either deck. The four bundled Creative Commons excerpts above are a separate playable collection.

DJcompanion inspired training ideas including pitch sensitivity, cue timing, waveform study, ear practice, EQ, and local track loading. Bit Cheer's lesson progression and implementation are its own.

Make a skin of your own

Download the template in Skin studio, edit skin.toml, and import it again. Choose a structural base and add your own panel, titlebar, background, frame, transport buttons, number atlas, platter, and pitch-panel images. Classic WSZ imports retain the original bitmap controls. You can start with this Electric Blue TOML example.
