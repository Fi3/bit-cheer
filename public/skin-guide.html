Make a bit.cheer skin.

SKIN GUIDE · FORMAT v1

Fastest way: use a museum skin

  1. Open skins.webamp.org and click a skin.
  2. Copy the address from your browser’s address bar, for example:
    https://skins.webamp.org/skin/5ea2d974dad5507b83a6ddff7003a8ee/Yufo06.wsz
  3. In bit.cheer, open Skin studio, paste the link and press Load skin.

If you already have a .wsz file on your computer, use Import a skin file instead.

Make your own in 4 steps

  1. In Skin studio, press Download template. You get a ZIP with skin.toml and a README.
  2. Unzip it and open skin.toml in any text editor.
  3. Give your skin a name and change the colors. Each color is a hex code like #b8ee75.
  4. Zip the folder again and press Import a skin file. Done. It stays saved on this device.
Only changing colors? You can import skin.toml on its own, no ZIP needed.

A minimal skin.toml

version = 1
name = "Sunset Walkman"
base = "millennium"   # the skin you start from

[colors]
background = "#1d1220"
panel      = "#6b3a5a"
panelLight = "#f2c6a0"
text       = "#fff4e8"
muted      = "#e9cbb8"
accent     = "#ffe08a"
secondary  = "#ff7a59"
screen     = "#2a0f2c"
border     = "#f0b48a"

Leave out any color and it keeps the value from the base skin.

What each color does

ColorWhere you see it
backgroundThe page behind the decks
panel / panelLightThe two ends of the metal panel gradient
text / mutedMain text and secondary text
accentLCD text, highlights and focus rings
secondarySmall second highlight color
screenThe deck LCD screens
borderBevels and outlines

Adding your own images (optional)

Put images next to skin.toml in the ZIP and list them under [assets]:

[assets]
titlebar = "graphics/titlebar.png"   # 275 × 14, the strip above the decks
buttons  = "graphics/cbuttons.png"   # 136 × 36, play / pause sprite sheet
numbers  = "graphics/numbers.png"    # 99 × 13, digits 0–9 (9 px each)
background = "graphics/bg.jpg"       # page background, any size
AssetSizeNotes
titlebar275 × 14Shown above the decks, scaled up
buttons136 × 36Two rows of 18 px: normal on top, pressed below. Play is at x 23, pause at x 46
numbers99 × 13 or 108 × 13Digits 0 to 9, 9 px wide each, shown 3× bigger on the BPM display
panel, background, frame, platter, pitchUp to 4096 × 4096Textures for panels, page, deck frame, jog wheel and pitch fader

Formats: PNG, JPG, WebP or BMP. Each image under 2 MB, the ZIP under 10 MB. Paths must be relative. Remote URLs, SVG and scripts are not allowed, so skins are always safe to load.

Base skin

Use base = "millennium". Your colors and images go on top of it. More bases are coming later.
